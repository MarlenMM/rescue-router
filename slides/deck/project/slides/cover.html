Rescue Router

Few-shot flood mapping and rescue routing with Chameleon

Track A + Track B

Marlen Melis · 20260876

Hello, I'm Marlen. My project is Rescue Router: I adapted Chameleon to map flooded roads and buildings in drone photos from only a few labelled photos — that's Track A — and built a system on top of the map that plans rescue routes by truck, boat and on foot — that's Track B. Five minutes: the problem and the best numbers, how I set it up, the results, and what I learned.
